# V49: звуки открытия яйца подгружаются заранее

Дата: 2026-11-17 · Файл места: `SpearHunt V49 - Sound Preload.rbxl` (V48 плюс `Client/Sfx` и `Client/Shop`)

## Зачем

Настоящие записи из Creator Store (V41) создаются при первом использовании и скачиваются из сети. Самое первое открытие яйца за сессию играло бы первые звуки (появление, нарастание, треск) с задержкой на загрузку, и они сбивались бы относительно анимации.

## Что сделано

`Sfx.preloadLibrary()` создаёт все 34 звука банка и вызывает `ContentProvider:PreloadAsync` в фоне. `Shop.open` вызывает её один раз за сессию: игрок смотрит магазин, звуки догружаются. Если игрок обходится без магазина, звуки грузятся как раньше, при первом использовании.

## Как проверено

В Play: до открытия магазина ни одного из 34 звуков нет в `SoundService`; через две секунды после открытия все 34 созданы и `IsLoaded = true`.

## Что не проверено

Скорость загрузки на телефонах и по мобильной сети (34 записи, самые длинные по 6–8 секунд); при желании можно ограничить предзагрузку первыми звуками сцены.
