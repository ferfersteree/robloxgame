# V44: окно шансов яйца показывало неполные проценты

Дата: 2026-11-17 · Файл места: `SpearHunt V44 - Odds Fix.rbxl` (V43 плюс новый `Client/Shop`; больше ничего не менялось)

## Ошибка

В окне ODDS у яйца первая строка («Mythic 10% · Legendary 23% · Epic 65%») пропускала самую высокую редкость. Цикл шёл по редкостям от 6 до 1, а их семь (Common … Divine). У Storm Heart Egg строка давала в сумме 98% (не было Divine 2%), у Astral Core Egg 95% (не было Divine 5%). Таблица под строкой была полной, но шансы нужно показывать честно и в сводке.

## Исправлено

- Сводка идёт по всем редкостям (`#Config.EXOTIC.RARITIES`). Проверено в Play для всех пяти яиц: строка равна 100% и совпадает с таблицей; серверные таблицы шансов тоже дают ровно 100,0000%, описания в магазине («Epic to Divine pets» и так далее) совпадают с таблицами.
- Заголовок «FOREST TALISMAN EGG» заходил под плашку «ALL RARITIES»; теперь он сжимается по рамке. Проход по всем текстовым подписям списка магазина (в том числе тем, что прокручены за край) обрезанных не находит; по всем десяти окнам игры тоже.

## Как проверено

- Файл: отличается ровно текст одного модуля (`Shop`).
- Окна шансов пяти яиц открыты в Play, строки считаны с экрана.
- Заодно прогнаны тестовые покупки всех 17 товаров (пассы, наборы, бусты, монеты, Starter Pack): без ошибок, ранг стал Diamond, сумка 90 мест (уровень 3 плюс +60 ранга), буст-таймеры сошлись с расчётом.

## Что не проверено

- Покупки за настоящие Robux (нужны Game Pass и Developer Products, их ещё нет).
