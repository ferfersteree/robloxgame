# V70: гантели и стойка CAMP GYM, новый HUD, магазин в зелёном стиле

Поверх V69. Концепты: Астра (Codex, medium), `docs/concepts_v70/` (картинки, `concepts.md`, концепт Hunter Pass `hunter_pass_ru.md`).
Доски в Claude Design: https://claude.ai/artifact/TLb6SBcAgyWYffx3S3tafT

- **Гантели**: 7 новых моделей по концепту (Wooden, Stone, Bronze, Iron, Granite, Golden со светящимся торцом, Mammoth с бивнями),
  собираются кодом `Util.dumbbell(level)` по таблице `Config.DUMBBELL_LOOK[i].parts`. Ими пользуются руки (Relay), превью (TrainCtl), стойка.
- **Стойка CAMP GYM** (`Util.gymRack`, `Server/Cosmetics`): при старте сервера в каждом участке старая стойка `Gym.Display` заменяется
  трёхъярусной деревянной стойкой на каменных опорах с вывеской. На полках все 7 пар; купленные уровни в цвете, остальные полупрозрачные «призраки»,
  текущая пара подсвечена. Гантель на земле (`NativeDumbbell`) — текущего уровня.
- **HUD** (`Client/Hud`): верхние карточки Coins / Strength / Bag / Level крупнее, с подписями и полосой опыта; меню слева в рамке,
  кнопки 220×60 с иконками; справа панель Quests с полосками. На телефоне компактное меню прежнее, верхняя полоса уменьшена.
  Карточка обучения и полоса активности опущены до y=100 (Guide, Activities).
- **Магазин** (`Client/Shop`): зелёная шапка в полоску, красный X, тёмный фон с точками, заголовки «~ Boosts ~», порядок:
  стартовый набор → Featured Egg (с шансами) → ранг → Boosts → Coin Packs → Game Passes (широкие плитки по 2) → Pet Eggs.
  Покупки, шансы, карточки «i», ODDS и сохранение не менялись. Кнопок подарка нет (подарков в игре нет).
- **Hunter Pass**: только концепт (`docs/concepts_v70/hunter_pass_ru.md`), в игру не встроен.

Проверено: check.py, Checker (Opus) по коду, плейтест Астры в Studio (HUD, магазин, стойка, тренировка; новых ошибок консоли нет).
После плейтеста поправлено: закрытые уровни полупрозрачные вместо тёмных, вывеска CAMP GYM поднята над верхней полкой,
стойка сдвинута на 0.5 студа к площадке (не заходит в грядку), плашка FEATURED не закрывает название яйца. Эти правки в Studio не смотрелись.
