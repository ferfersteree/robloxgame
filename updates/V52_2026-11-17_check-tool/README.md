# V52: проверка репозитория одной командой

Дата: 2026-11-17 · Файла места нет: меняются только инструменты (`tools/check.py`), игра остаётся `SpearHunt V51 - Spear Models.rbxl`.

## Зачем

Перед тем как назвать работу законченной, нужна быстрая проверка без Studio. Раньше я запускал три скрипта по отдельности и сверял глазами; теперь это одна команда: `python tools/check.py`.

## Что проверяется

1. Синтаксис всех `.luau` в `source/` и `tests/` (`tools/luau_check.py`, 112 файлов).
2. Имена без объявления: опечатки и локальные функции ниже места вызова (`tools/luau_names.py`).
3. Блок моделей копий 41–46 в `SpearFactoryV15.luau` совпадает с тем, что рисует `tools/spear_models.py`, и в каждой модели не больше 1100 кубиков.
4. В `README.md` назван новейший файл места, и он лежит в корне.
5. В отслеживаемых текстовых файлах нет присвоенного значения `ROBLOX_API_KEY`.

Код возврата 0 только если всё в порядке. Проверено на плохих файлах: синтаксическая ошибка и вызов функции, объявленной ниже, дают FAIL.

## Чего не заменяет

Проверку в Studio: звук, вид, ввод мышью и клавишами, DataStore, телефон.
