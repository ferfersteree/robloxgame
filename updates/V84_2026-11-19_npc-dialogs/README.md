# V84: диалоги с NPC в новой рамке

Поверх V83.

## Окно диалога (`Client/Dialog`, `Client/UIKit`)
- Окно собрано из картинок Астры (лист `ui-art/source/dialog_frames.png` → `ui-art/atlas/sh_atlas7.png`, в Roblox 82270850809307):
  бирюзовая бамбуковая рама с верёвками в углах, портрет в деревянной рамке, кремовая плашка реплики с хвостиком к портрету,
  деревянная табличка имени с листком, золотой значок «дальше». Предпросмотр: `docs/concepts_v84/dialog_preview.png`.
- Кнопки дел из общего набора с иконками вместо эмодзи (Collection, Quests, Potions, Spears, Market, Forge), красный крестик как у окон.
- Под портретом подпись роли NPC. В углу плашки номер совета («Tip 2 / 6»).
- Клик по плашке или «Next» во время печати допечатывает реплику сразу, следующий клик открывает следующую.
  Раньше быстрые нажатия «Next» запускали две печати на одной надписи.
- Если картинок листа 7 нет в `UI.ART`, окно собирается из старых (`panel_quests`, `card_7`, `row_cream`, `sign_wood`).

## Реплики (`Shared/Config` → `Config.NPC`, `Client/Dialog`)
- Порядок: приветствие (при первом разговоре за сессию одно, потом другое), задание этого NPC с прогрессом
  («…So far: 3 of 5») или с наградой, подсказка по прогрессу игрока, дальше советы по кругу.
- Подсказки по прогрессу: Tracker — до какой зоны долетает бросок при нынешней Силе и сколько Силы нужно до следующей;
  Armorer — следующее копьё и сколько монет не хватает; Merchant — сколько добычи в рюкзаке; Blacksmith — уровень ковки
  копья в руках; Quest Board — сколько заданий открыто и готово.
- Советы переписаны под нынешнюю игру (красный пол зоны броска, ступени множителя, срыв хвата, гантели, пропуск, питомцы, вулкан);
  устаревшие («Step inside…», «Even the air is green in the Wild Marsh») убраны. У каждого NPC теперь 3–6 советов вместо 1–4.
