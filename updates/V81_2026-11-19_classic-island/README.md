# V81: приземление без рывка, остров в прежнем стиле

Поверх V74. V75–V80 были промежуточными сборками для замеров и проверок в Studio (их файлы в корне можно удалить).

## Замеры в Studio (строки `[Perf]`; обычный кадр в этом окне Studio 26–30 мс)
| Сборка и режим | Самый длинный кадр за 1,2 с после приземления | Старт сцены улова (prep) |
|---|---|---|
| V74, старый путь (`PerfLegacy = true`) | 197–213 мс | 153–165 мс |
| V74, новый путь | 43–176 мс | 6,5–163 мс |
| V75 (индекс деталей по клеткам) | 39–45 мс | 8,4–9,1 мс |
| V76 (свежий список в кадре старта: откат) | 72–76 мс | 39–40 мс |
| V77 (список снова во время полёта + журнал новых деталей) | 43–44 мс, всплески каждые 0,08 с | 14–18 мс |
| V78 (проверка заслоняющих деталей порциями) | 33–41 мс | 3,1–3,5 мс |
| V79 | 26 мс (один бросок) | 2,4 мс |
| V80 (дальний бросок; в той же сессии премиум и окно пропуска) | 41–42 мс | 2,2–2,5 мс |

Что было причиной и что сделано (`Client/RevealOcclusion`, `Reveal`, `SpearFx`, `WorldFx`, `AnimalRig`, `HuntCtl`):
- `Occlusion.begin` обходил все ~150 тысяч деталей мира в кадре старта сцены. Теперь детали один раз в фоне раскладываются по клеткам
  64×64; список рядом с точкой собирается во время полёта копья порциями, детали, появившиеся позже, добавляются из журнала.
- Проверка «что заслоняет зверя» шла полным проходом раз в 0,08 с (всплески по 10–15 мс весь показ). Теперь небольшая порция каждый кадр,
  от точки наружу.
- Копьё из 40+ деталей не сжимается каждый кадр, волна кубиков берёт кубы из запаса и строится за 3 кадра, куст и зверь строятся заранее.

## Остров (`Server/Relay`, флаги в начале файла)
- `REMOVE_COURSE = true`: полоса препятствий убирается с карты целиком. Задание q7 стало «Do 25 dumbbell reps», задание пропуска dD2 —
  «Score 40 points at the target range».
- `RESTYLE_MATERIALS = false`: материалы не меняются, остров в прежнем виде (пластик с шипами).
- `KEEP_GROVE = false`: на месте музея ничего не строится (true вернёт рощу из 94 деталей в прежнем стиле, `CLASSIC_STYLE`). Музей убран.
- Длинная трасса V74 и перекраска материалов остались в коде и включаются этими флагами.

## Прочее после V74
- Карточка улова выше на 16 единиц (кнопка Collect не обрезается); `UI.artApply` всегда делит по высоте картинки с растяжением только
  по горизонтали (Sell All обрезалась); вкладки биомов в Collection слева и прокручены к выбранному; табличка редкости на баннерах яиц шире;
  значок надетого питомца не налезает на меню; ошибка в `petToggle` не блокирует кнопки.
- `Server/Shop`: уровень пропуска, забранный до V74 как монеты или Сила, не выдаётся второй раз.
- Hunter Pass: у награды с кнопкой CLAIM название тоже в две строки (V81). Проверено в Studio (V80): премиум включается тестовой покупкой, зелье и осколки забираются, таймер зелья появляется.
