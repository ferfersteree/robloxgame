# V85: гантели и стенды в аниме-стиле

Поверх V84.

- 15 гантелей и 15 стендов CAMP GYM из мешей Claude Design (`docs/concepts_v83`): загружены в Roblox, раскрашены по материалам
  GLB и лежат в `ReplicatedStorage.GymMeshes` (DB_01..DB_15, ST_01..ST_15).
- `Shared/Util`: `Util.dumbbell` и `Util.gymRack` берут меши; если их нет — прежние модели из деталей (`Util.dumbbellParts`).
  На стенде текущая пара стоит на месте из данных дизайнера; прошлых уровней на полках больше нет (так в дизайне).
- Эффекты по `fx_table.md`: искры цвета уровня (с 1-го), свет у светящихся уровней (5, 6, 8–15), без Beam и Trail.
- Проверено в Studio: стенд уровней 1, 8 и 15 на участке игрока, гантели уровней 1 и 15 в руках при тренировке.
- Место сохранено из Studio (File → Save to File As), потому что меши нельзя добавить через `patch_many.py`;
  все 139 скриптов совпадают с `source/`.
