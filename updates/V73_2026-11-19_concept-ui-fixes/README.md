# V73: правки пропуска и HUD

Поверх V72. Изменены `Client/UIKit`, `Client/Hud`, `Client/Menus`.

- `UI.artApply`: картинки, у которых растягивается только середина по горизонтали (кнопки, полосы, плашки), больше не обрезаются снизу.
  Причина: Roblox при нулевых верхнем и нижнем краях и заданном SliceScale показывал только верхнюю часть спрайта.
- Hunter Pass: название задания в две строки; где яйца закрыты по региону, плитка показывает монеты (их и выдаёт сервер) без кнопки ODDS;
  нет всплывашки «+0 Pass XP» на максимальном уровне.
- HUD: панель Quests шире, названия заданий в две строки и не мельче 13; слот копья виден и работает только в обычном режиме.
