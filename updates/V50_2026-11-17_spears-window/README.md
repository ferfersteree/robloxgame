# V50: окно копий открывается без подвисания

Дата: 2026-11-17 · Файл места: `SpearHunt V50 - Spears Window.rbxl` (V49 плюс новый `Client/Menus`)

## Что было

Окно копий (кнопка SPEARS, лавка Armory) на странице показывает шесть копий, и у каждой в рамке крутится своя 3D-модель из сотен деталей. Все шесть создавались в одном кадре: замер открытия в Studio 252 мс (в этой тестовой Studio кадр 15 FPS, на телефоне будет заметно хуже), то есть подвисание при каждом открытии и перерисовке.

## Что сделано

Модель каждого копья создаётся отдельной задачей с шагом 0,04 с, а не все сразу. Вызов открытия окна занимает около 12 мс, а шесть копий появляются одно за другим за четверть секунды. Если окно перерисовали или закрыли раньше, отложенные модели не создаются.

## Как проверено

В Play: вызов `Menus.spears` 11,6 и 12,0 мс (было 251,6); сразу после вызова 0 моделей, через 1,5 секунды все 6; консоль чистая; последующие покупка и надевание копья (V48) не затронуты.

## Что не проверено

На телефоне. Окно сумки (93 мс при пустой сумке) и «Животные» (117 мс) устроены похоже; сумку с большим числом животных я не мерил, их карточки можно строить так же по кадрам.
