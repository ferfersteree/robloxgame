# V89b: телефон: исправления по проверке V89

Поверх V89. Файл места `SpearHunt V89b - Phone Fixes.rbxl` собран `tools/patch_many.py` из V88 с теми же четырьмя скриптами (UIKit, Hud, Main, WorldFx), что и V89, плюс правки ниже; все 169 скриптов совпадают с `source/`.

**Что исправлено**
- **Полосы зоны нажатия и слой окна.** Кнопки HUD под открытым окном (слот копья) раньше считались соседями и без нужды отнимали зону нажатия у кнопок окна: затемнение окна `Overlay_*` на весь экран всё равно перехватывает ввод.
  Теперь кнопки слоёв ниже открытого окна в соседи не берутся. Окно Shop на эмуляции телефона 812×375: у всех 28 мелких кнопок есть полосы (в V89 у одной не было; причину в описании V89 я сначала указал неверно, исправлено там же).
- **«Reduced Effects» и сцена яйца.** Сцена яйца выключает Bloom и SunRays на время сцены и в конце возвращает их. Если «Reduced Effects» включались во время сцены (в том числе сами на телефоне), Bloom и SunRays после сцены оставались включёнными.
  Теперь пока режим включён, такое «возвращение» гасится заново; при выключении режима включаются только эффекты, которые отключили мы. Проверено в Studio: включить режим, имитировать возвращение эффектов, выключить режим.
- **Порог самовключения «Reduced Effects»** на телефоне: медиана кадра дольше 42 мс (меньше 24 кадров в секунду) две проверки по 12 с подряд, раньше было 28 мс (меньше 36 кадров в секунду). При 28 мс телефон, который стабильно держит 30 кадров, получал бы режим всегда.

**Проверено в Studio** (Play, эмуляция телефона): Shop 28 из 28 мелких кнопок с полосами, в окнах Spears, Bag и Hunter Pass полосы не заходят на соседей, режим эффектов включается и выключается без остатков, консоль чистая.
Независимая проверка кода разобрала этот набор правок: найдено только состязание со сценой яйца (исправлено выше).
**Не проверено:** настоящий телефон (касание, вырезы экрана, FPS, память, время входа), самовключение «Reduced Effects» вживую (на ПК кадры быстрые), Wrap (нужен пасс), яйца и покупки за Robux вживую, DataStore вживую.
