# V74: лаг приземления, питомцы, лавки, остров, награды пропуска

Поверх V73. Концепты: `docs/concepts_v74/`. Картинки: лист 6 в `ui-art/`.

- **Приземление копья** (`SpearFx`, `WorldFx`, `Reveal`, `RevealOcclusion`, `AnimalRig`, `HuntCtl`): копьё из 40+ деталей больше не
  сжимается каждый кадр (ScaleTo по ~1100 деталям), а исчезает со вспышкой; волна кубиков берёт кубы из запаса и строится за 3 кадра
  (не больше 80 кубов); эффект удара на кадр позже; куст и зверь для сцены улова строятся заранее, пока копьё летит.
  В Studio в консоль пишутся строки `[Perf] land …`, `[Perf] hitch max_dt=… mode=new|legacy`, `[Perf] reveal …`.
  Старое поведение для сравнения: атрибут `ReplicatedStorage.PerfLegacy = true`.
- **Питомцы** (`Shop`, `PetAnim`): наземные бегут за игроком по земле и садятся рядом, когда он стоит; летающие парят и машут
  крыльями; плавающие скользят над землёй. Тип берётся из таблицы по виду.
- **Рюкзак**: вкладки Catch и Pets (надеть, снять, счётчик 2/3, кнопка Collection).
- **Окна лавок и меню** (`Menus`, `UIKit`): деревянная вывеска с иконкой, ячейки, строки, кнопки, карточки по редкости, зелья, плашки
  цен рынка — из картинок. Яйцо Astral Core получило свою картинку.
- **Остров** (`Server/Relay`, при старте сервера): музей убран, на его месте роща; полоса препятствий из 39 этапов с движущимися
  стенками, вращающимся бревном, мигающими платформами, маятниками и финишем на высоте 18; материалы стартового острова по цвету
  детали (трава, дерево, камень, песок, кирпич) без шипов. Выключатель материалов: `RESTYLE_MATERIALS` в начале `Relay.luau`.
- **Hunter Pass**: в премиум-ряду вместо монет и Силы зелья Травницы на 15–30 минут, осколки питомцев, новые метки и аура,
  ещё одно яйцо и Jackpot Hour. По ценам магазина ряд стоит 1 847 R$ (в 6,2 раза больше цены пропуска; было 1 689 R$).
