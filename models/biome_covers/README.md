# Кусты биомов в виде моделей (Blender)

25 моделей `spawn_cover_01..25`, один в один из рисунков V61 (`tools/biome_covers.py`): те же воксели 0.5 стад, три части
у каждого куста (`Core`, `LeftLobe` на -X, `RightLobe` на +X), ширина 10.5 стад, перед смотрит в -Z (как в Roblox).

- `spawn_cover_NN.fbx`: импорт в Studio (Asset Manager → Bulk Import). Цвет лежит в атрибуте цвета граней, один общий материал.
- `biome_covers.blend`: все 25 в одной сцене, сетка 5×5.
- Размер при импорте проверьте: должно быть 10.5 стад в ширину; если нет, поправьте масштаб в импортёре.
- Игра эти файлы пока не использует: кусты в V62 строятся из воксельных данных. В Studio импорт не проверялся.
