# V83 — таблица эффектов, 15 уровней

Эффекты лежат в дочерних коллекциях `<модель>_FX` и в GLB не попадают. Светящиеся части самой модели (руны, лава, глаза, надписи) в GLB есть — в Roblox им ставится материал Neon.
Частоты и размеры — стартовые значения на глаз по рендерам, в игре не проверялись.

Общие рецепты:
- **Искра / блёстка** — ParticleEmitter с текстурой четырёхлучевой звезды, Size-кривая 0→1→0, LightEmission 1.
- **Аура / дымка / туман** — ParticleEmitter с большой мягкой круглой текстурой, Transparency 0.8–0.9, LightEmission 1, плюс PointLight.
- **Молния** — Beam между двумя Attachment с зубчатой текстурой; раз в 0.6–1.5 с включать на 0.1–0.2 с и менять CurveSize.
- **Пламя** — два ParticleEmitter (внешний и жёлтая сердцевина), Acceleration вверх, Size 1→0.
- **Орбита / кольцо** — MeshPart Neon, вращаемый скриптом, или Beam по окружности.
- **След при взмахе** (в Blender нет, рекомендация для уровней 9–15) — Trail между двумя Attachment на голове гантели, Lifetime 0.25.
